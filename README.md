# Gestor de Fretes 🚚

Sistema para motoristas e empresas organizarem seus fretes de forma simples e prática.

## Funcionalidades planejadas

- Registro de entregas e coletas
- Controle de abastecimentos
- Quilometragem por viagem
- Ganhos e gastos por período
- Painel de resultados e resumos
